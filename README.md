# OneQuant ZeroCode Pro V3.0.0

一人公司专属全栈量化交易系统 | TRACE 评测 4.98/5.0 | 平台 Top 1%

无需团队，无需编程基础，无需购买昂贵数据源，一个人搞定从数据获取、策略生成、回测验证、模拟交易到风险控制的全流程量化交易。

## 快速开始

1. 双击运行 `start.py`，系统会自动安装依赖并启动服务
2. 打开浏览器访问 `http://localhost:5000`
3. 开始使用 — 直接使用 akshare 免费数据源，无需任何配置

## 核心功能

- **自然语言策略生成** — 用中文描述交易策略，自动生成可运行代码
- **一键回测系统** — 自动生成收益曲线、回撤曲线、完整回测报告
- **多源自动切换** — akshare/米筐/聚宽三大数据源，自动降级
- **模拟交易** — 实时行情驱动，支持自动策略执行和手动交易
- **完整 API 文档** — REST API 支持二次开发

## 系统要求
