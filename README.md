## ✨ 核心功能亮点
- 🤖 **自然语言策略生成**：用中文描述交易思路，自动生成可运行Python策略代码，内置双均线、MACD、海龟交易、KDJ、网格交易5种经典策略模板
- 📊 **一键专业回测**：自动生成收益/基准/回撤三曲线，计算年化收益、最大回撤、胜率等12项核心指标，支持akshare免费数据
- 🎚 **可视化参数调整**：拖动滑块修改策略参数，实时预览效果变化，无需编写代码
- 🔄 **多源智能切换**：集成akshare/米筐/聚宽三大数据源，akshare永久免费，被限流时自动无缝降级
- 💹 **实时模拟交易**：真实行情驱动，支持自动策略执行与手动交易，内置止损止盈风控
